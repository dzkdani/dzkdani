## Featured Projects

### [Far From Shore](https://dzkdani.github.io/work/far-from-shore/)

A data-driven narrative survival game that plays in the browser, built in Unity with WebGL. Built a modular state-management system on structured data layouts to handle player choices and action point (AP) allocation; optimized the WebGL build with aggressive code stripping and asset compression for fast browser loads.

### [G-Escape](https://github.com/dzkdani/gescape)

Fast-paced vertical arcade shooter. High-performance gameplay loop with precise collision detection and efficient object pooling for dynamic entities; tuned for responsive input and fluid 60 FPS play on web and mobile.

### [Math Adventure](https://github.com/dzkdani/math-adventure)

Educational isometric game and client project. Fully optimized dynamic asset delivery with Unity Addressables for modular map streaming, cutting initial build size and runtime memory overhead on mid-to-low tier hardware.
